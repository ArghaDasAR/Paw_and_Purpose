# 🐾 Paws & Purpose

### More Than Pets. Family.

**Paws & Purpose** is a modern, responsive pet-care and animal-focused web experience designed to connect people with the world of pets through a clean, welcoming, and user-friendly interface.

🌐 **Live Demo:** [pawsandpurpose.vercel.app](https://pawsandpurpose.vercel.app/)
💻 **Repository:** [GitHub Repository](https://github.com/ArghaDasAR/Paw_and_Purpose)

---

## ✨ About the Project

Paws & Purpose was created with one simple idea:

> **Pets aren't just animals. They're family. 🐾**

The website focuses on creating a warm and modern digital experience for pet lovers while keeping the interface intuitive, responsive, and visually engaging.

The project combines a minimalist design approach with modern frontend development practices to create a website that works smoothly across desktop and mobile devices.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/ArghaDasAR/Paw_and_Purpose.git
```

### 2. Navigate to the project

```bash
cd Paw_and_Purpose
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.
